# Asynchronous Cathedral（异步大教堂）

> 一套生成式美学宣言 —— 为「Tensor Core 优化阶梯」的可交互可视化而写。
> 与 [[PHILOSOPHY-latency-cartography]]（CUDA core 篇）同源，但讲的是另一种藏延迟之道。
> （algorithmic-art skill 的第 1 步：先立哲学，再用代码表达。）

## 运动名称

**Asynchronous Cathedral —— 异步大教堂**

一座由少数专职工匠维系的巨型引擎之殿：生产者只管搬运、消费者只管计算，二者用信号（mbarrier）隔空交接，让那台吞吐惊人的张量核永不停歇。这里，**空旷（极低的占用率）不是荒废，而是大师的从容**——殿堂里没有挤满人，却比任何拥挤的厂房产出更高。

## 哲学

CUDA core 篇（延迟制图学）讲的是「把数据搬近 + 用独立指令填满等待」；张量核篇要讲一件更激进的事：**当计算引擎快到一个数量级，藏延迟的方式必须从「人多」变成「流水」。** 张量核一条指令吞下一整块 16×16×16 的矩阵乘，快得吓人——可正因为它太快，喂数据的那条路反而成了瓶颈。整部张量核优化史，就是一场「如何让一台几乎瞬时的引擎永远有料可吃」的工程史诗。

朴素的开局是悲剧性的：32 个线程吭哧吭哧把一小块数据从最远的全局内存搬进寄存器，张量核算一下，又去搬——殿堂建好了，神坛却空着，引擎大部分时间在干等（SM Busy 仅 17%）。可视化要让人一眼看到这种**反差的荒诞**：一台炫目的引擎，旁边堆满疲于奔命的搬运工，而它本身明灭不定、形同虚设。随着 shared memory 复用、cp.async 异步预取一步步加入，搬运不再阻塞计算，引擎的明灭渐渐连成稳定的光——但仍未饱和，因为 warp 级的 WMMA 始终要先把数据"过一道寄存器"，且依赖人多势众（高占用率）来勉强遮掩延迟。

真正的质变是建筑学意义上的：Hopper 把殿堂重新设计。**TMA** 让一个线程发起一整块的异步搬运，走专用通道，不再用成群的访存指令堵死缓存；**WGMMA** 让操作数直接从共享内存喂进张量核，绕过寄存器中转；**warp specialization** 把工匠分成生产者与消费者两班，用 **mbarrier** 隔空击掌、循环交接。于是奇迹出现：每个 SM 上几乎空无一人（占用率 7.6%），张量核却被喂到 83% 的忙碌——**用深度异步流水线，彻底取代了堆砌 warp 的笨办法**。可视化的高潮，正是这一刻的视觉反转：拥挤褪去，殿堂空灵，而中央的引擎第一次燃成不灭的实心之光。

这是一件**精雕细琢、历经无数次推敲**的算法作品。生产者与消费者之间那一来一回的信号、数据包穿过专用通道时的色温、流水线各级错开半拍的节奏，都应像出自一位深谙 Hopper 体系结构与计算美学的大师之手——既忠实于硬件的冷峻真相（所有数字皆 H20 实测），又有建筑般的秩序与留白之美。它要让"异步"这个抽象到反直觉的概念，变成可以肉眼感受的、令人信服的从容流动。

它必须**新手友好**：张量核、fragment、WMMA、warpgroup、TMA、mbarrier、warp specialization——每一个名词都先于使用之前用最朴素的比喻交代背景与目标，绝不堆术语。最难的异步概念用最简单的画面承载：两班工匠隔空击掌讲清生产者/消费者，一条粗descriptor箭头讲清 TMA，半大的数据包讲清 FP8。**思想要简单直观，画面要一眼看懂，工程深度要经得起专家推敲**——三者同时达成，正是这件作品追求的至高匠艺。

## 概念种子（埋在算法里的隐线）

母题是**「让引擎永不挨饿」**。所以每一幕都在追问同一个问题：*此刻，张量核有料可吃吗？* 朴素 WMMA 的答案是「没有，它在等搬运」；登顶 WGMMA 的答案是「有，生产者早已把下一块异步搬好，流水线永远超前一步」。观者哪怕不懂 Hopper，也会本能地感到画面从「闪烁的饥饿」走向「饱满的轰鸣」——而懂行的人会心一笑：这正是从 Ampere 到 Hopper、GEMM 工程范式迁移的全部精髓。

## 表达方式（交给实现的指引）

- **活的算法，而非静态图**：五级（WMMA naive → smem → cp.async → WGMMA+TMA+WS → FP8）各是一个随时钟演化的循环动画——搬运、计算、信号交接、瓶颈暴露、下一级修复它。
- **延续的视觉语言**：沿用 CUDA core 篇的内存阶梯骨架（全局/共享/寄存器），但在顶端换上**张量核引擎**这一新主角；用「SM Busy 实心光」「生产者/消费者两班」「mbarrier 击掌」「TMA 专用粗通道」「数据包半身（FP8）」作为新语汇。
- **核心反转要拍出来**：占用率从 71% 跌到 7.6%、SM Busy 从 17% 涨到 83% 的同框对比——拥挤的衰败 vs 空灵的繁荣，是这件作品的灵魂一击。
- **重点突出**：每一幕只主推一个核心洞察，细节交给文字面板；动画负责「直觉」，文字负责「精确」。
- **忠于实测**：所有 GFLOPS、利用率、SM Busy、占用率、warp cyc/issue 均来自 H20（Hopper, CC 9.0）真机 `ncu --set full`。
